A repository containing a binary file, which contains the raw header data from a Hondex KD05-C memory card.

This header data must be present on any CF card that you wish to use with a Hondex plotter, and can be added to the first sector of a blank CF card in order to make it functional.

The software used to create the file is Active© Disk Editor, and can be used to open this file, as well as edit the raw data on the CF card.
